# 🧠 Sentiment AI — NLP Based Sentiment Analysis

A Natural Language Processing (NLP) project that analyzes movie reviews and classifies their sentiment as **Positive** or **Negative** using the **IMDb Movie Reviews Dataset**.

This project was built as a practical implementation of the NLP concepts I had previously studied theoretically. It helped me understand how raw text can be processed, transformed into useful features, and used to make meaningful sentiment predictions.

---

## 🚀 Features

- 📝 Analyze movie reviews
- 🧹 Text preprocessing and cleaning
- 🔤 Tokenization and feature extraction
- 🧠 Machine Learning based sentiment classification
- 📊 Model training and evaluation
- 🌐 Flask-based web application
- ⚡ Real-time sentiment prediction
- ✅ Positive/Negative sentiment output

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/khushi123438/Sentiment-AI.git

cd Sentiment-AI
```

### Create Virtual Environment
```bash
python -m venv venv
```

## Activate Virtusl Environment

For Windows:
```bash
venv\Scripts\activate
```
Install Dependencies :
```bash
pip install -r requirements.txt
```

## ▶ Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

---

## 🎯 How to Use

1. Open the web application.
2. Enter a movie review in the input field.
3. Submit the review.
4. The NLP pipeline processes the text.
5. The trained model predicts the sentiment.
6. View the Positive or Negative prediction.
